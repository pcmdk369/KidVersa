# KidVersa™

**Play · Learn · Create · Explore**

KidVersa is a child-friendly games platform for ages 9–12, designed for web and Android. The project prioritizes genuinely playable games, accessible controls, privacy, and age-appropriate experiences.

## Product principles

- No public chat, location sharing, or targeted advertising.
- No manipulative monetization or dark patterns.
- Touch-first controls with keyboard support where practical.
- Clear parental controls and minimal data collection.
- Learning and creativity are integrated into play.

## Planned game worlds

- Speed Racers — arcade racing
- Adventure Quest — exploration and platform challenges
- Creative Builder — sandbox construction
- Brain Academy — logic, memory, mathematics, and science
- Sports Arena — accessible sports mini-games
- Space Explorer — space discovery

## Development status

This repository is being initialized. Features are not considered production-ready until implemented, tested on supported browsers/devices, and reviewed for child safety and privacy.

## Planned stack

- React, TypeScript, and Vite
- Phaser for 2D games
- Capacitor for Android packaging
- Backend and persistence to be selected after the offline-first MVP is validated
